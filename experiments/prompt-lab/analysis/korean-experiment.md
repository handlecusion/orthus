# 미측정 영역 검증 — 순한글 3박자 조건 (2026-07-19)

## 질문

"한국어모델–한국어wiki–한국어지시" 3박자가 정합하면 한국어 지시문(kr-v1)이 이기지
않나? 앞선 kr-v1 기각은 실제 회사 코퍼스(한글 15.9%/영어 48.2%, 근거 한글비율
median 0.42)에서 측정한 것이라 "순한글 wiki" 조건은 미측정이었다.

## 설정 — 합성 순한글 코퍼스

- gpt-4o로 영상/아틀라스 제작사 맥락의 **순한글 회사 문서 60개** 생성 (영어 금지
  지시, **한글비율 median 0.91**, min 0.81 — 실제 코퍼스 0.42의 두 배 이상).
- distill A/B: baseline vs kr-v1, 판정자 gpt-4o (원문 동봉), 60문서 paired.
- wiki_qa A/B: 각 문서 claim에서 한국어 질문 역생성(60문항) → 합성 frozen hits
  (정답 claim + distractor, **근거 한글비율 median 0.84**) → 답변 A/B → 쌍대 판정.
- ⚠️ 합성 코퍼스라 prod 대표성은 없다. 오직 언어-정합 가설의 조건부 성립만 잰다.

## 결과 1 — distill (순한글 60문서)

| 지표 | baseline | kr-v1 | 검정 |
|---|---|---|---|
| claims/doc | 9.32 | 8.37 | kr가 더 적게 추출 |
| 오염률 | 0.36% | 0.80% | 문서단위 McNemar 1:3, p=0.63 |
| 커버리지 | 82.2% | 83.4% | per-doc sign 14:8, p=0.29 |
| 메타-claim | 0% | 0% | — |

→ **무차이 (혼합 코퍼스와 동일 결론).** 순한글이라 양쪽 다 오염이 훨씬 낮다
(합성 문서가 깨끗·자기완결적이라 환각할 여지가 적음) — 그러나 baseline vs kr-v1
격차는 여전히 비유의.

## 결과 2 — wiki_qa (순한글 근거 60문항) ★결정적

| 지표 | baseline | kr-v1 |
|---|---|---|
| 판정 승수 | **14** | 1 (tie 45) |
| sign test | **p=0.0010 — baseline 유의 승** | |
| 거부형 답 | **0** | 3 |
| 답변 길이 median | 82자 | 57자 |

→ **혼합 코퍼스와 동일하게 kr-v1 유의 패배** (혼합: 33:11 p=0.0013 / 순한글:
14:1 p=0.0010). 순한글에선 baseline이 거부를 0건 낸 것 대비 kr-v1이 더 소극적.

실패 예시 (근거는 순한글, 질문도 한국어):
- Q "출연료 정산 내역은 언제 발송되나요?"
  baseline: "매주 금요일까지 발송…익주 월요일 지급…2023-11-01부터 적용" /
  kr-v1: "매주 금요일까지 발송됩니다." (시행일·지급일 누락)
- Q "11월 16일 촬영 장소는?" baseline: "경기도 파주시 파주 아트빌리지, 섭외 완료" /
  kr-v1: "경기도 파주시 파주 아트빌리지입니다." (상태값 누락)

## 판정 — 가설 기각

**3박자를 모두 정합시켜도 한국어 지시문은 이기지 않는다.** distill은 무차이,
wiki_qa는 유의 패배 — 둘 다 혼합 코퍼스 결론과 동일하다. kr-v1의 패인은 언어
이해 정합이 아니라 **행동 프라이어 변화**임이 확증됐다: 한국어 지시문이 Solar를
더 짧고 소극적으로 만든다(길이 82→57자, 거부 0→3). 이 효과는 근거·질문의 언어와
무관하므로, wiki를 순한글로 바꿔도 결론이 바뀌지 않는다.

**prod 함의**: 영어 지시문 유지 결정은 코퍼스 언어 구성과 독립적으로 유효하다.
회사가 향후 순한글 위키로 가더라도 이 세 채택(cite-v2·strict-v1·syn-v2)과 기각
(kr 한국어화)은 그대로 성립한다.

## 남는 한계

합성 코퍼스는 실제보다 깨끗해 오염 바닥이 낮다(0.4% vs 5%). 하지만 두 프롬프트를
같은 60문서에 paired로 비교하므로 A/B 결론에는 영향 없다. 진짜 순한글 **실무**
코퍼스(예: 순한글 노션)가 생기면 재확인 가치는 있으나, 방향 반전을 기대할 근거는
없다.
