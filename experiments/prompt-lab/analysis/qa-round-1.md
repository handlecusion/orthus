# Track A round 1 — wiki_qa 지시문 한국어화 (kr-v1) (2026-07-19)

## 설정

- 기준 위키: Phase 2 로컬 재구축 (Solar distill 현행 프롬프트 + Solar
  embedding-passage 대칭, 1,972 docs → 13,851 chunks, 혼재 0)
- 골든셋: 재구축 위키 페이지 70개(실함 300자+ 50 / 중간 150–300자 20)에서
  역방향 생성, 생성기 2종(Solar·gpt-4o) × 페이지당 1문항 = **140문항**, 제목
  누출 자동 표기
- frozen hits: 문항당 production `retrieve()`(k=5, company) 1회 캡처 — 모든
  변형이 같은 hits 위에서 경쟁
- 답변: `answer_from_hits`(learn=False, record_gaps=False), Solar
- 판정: gpt-4o, 익명 A/B + 양방향 스왑 + 불일치=tie, **근거 동봉**

## 판정

**기각 — 현행(영어 지시문) 유지.** Track C와 반대로 여기선 방향이 명확히
역효과: 한국어 지시문이 Solar의 답을 더 짧고 소극적으로 만들었다(거부 2배).
"한국어 모델이니 한국어 지시가 낫다"는 가설은 두 표면(distill·qa) 모두에서
성립하지 않았고, qa에서는 유의하게 해롭다.

## round 1의 진짜 발견 — 인용 마커 위반 57%

결정론 검사(프로덕션 `_ANSWER_CITATION` 정규식): **baseline 57.1% / kr-v1
59.3%가 인용 마커 금지 규칙 위반** ("[1]", "(참고: [1] 발췌 기반)", "출처:
[3]").

이중 피해: ① 사용자 화면에 죽은 참조 노출(인터페이스가 출처를 따로 보여줌)
② `_should_learn`이 인용 마커 답변의 T2 학습을 거부 → **답변 과반이 위키로
축적되지 못함**. 현행 금지 문구는 프롬프트 중간 한 줄 — Solar가 대부분
무시한다.

→ round 2 (`cite-v1`): 금지 규칙을 말미 재강조 + 금지 예시 열거 + "참조가
필요하면 대상 자체(프로젝트/날짜/사람)를 명명하라"로 재작성. **1차 지표 =
결정론 위반율 paired McNemar** (판정자 불필요), 2차 = 판정자 쌍대(품질 회귀
방지).
