# D9 사전선언 — "현행 GPT → 국내 모델 교체, 손해 없나?" (비열등성 검정)

> 상태 **LOCKED 2026-07-17** (baseline 캡처 시작 전 잠금, 결과 미확인 상태에서 작성).
> D7 prereg §1(무효원칙)·§7(다중비교)·§8(반박문답)을 상속한다.

## 1. 왜 이 측정을 하는가 (D8과 다른 질문)

D6~D8은 **국내 3모델끼리의** 대결이라 `gpt-4o-mini`가 판정셋을 한 번도 풀지 않았다.
따라서 "R+ 98.8%"는 **현행 대비 개선을 뜻하지 않는다.** 그런데 owner 결정(2026-07-14
chat, 2026-07-17 임베딩까지 확대)으로 **GPT 이전은 이미 확정 사항**이고, 남은 실무 질문은
"옮기면 얼마나 손해인가"다. 이건 우월성이 아니라 **비열등성** 질문이다.

⚠️ **동기 고지(정직성):** 본 측정은 owner가 "국내가 낫다 혹은 바꿔도 손해없다"를 원한다고
밝힌 뒤 착수했다. 그러므로 **결과를 보기 전에** 판정 기준·마진·문안을 아래에 고정한다.
`model-orchestration.md` §11.3b의 기존 실측(decompose에서 **국내가 유의하게 짐** —
gpt 93.8 vs Solar 81.2)은 **철회하지 않으며**, 본 측정 결과와 병기 보고한다.

## 2. 측정 대상 (딱 하나만 바꾼 A/B)

판정셋 = `golden/t3_d8_holdout.json` **1,438문항** (D8과 동일, gold 동결, 재생성 금지).

```text
공통 글루(양 arm 완전 동일 — 오직 1차 워커만 교체):
  k=5 자기일관성(t0 + 4×t0.7, 실행결과 null제외 다수결) → snap → 결정론 수리(repair.py)
  → probe-0 → null 폴백(ax → exaone)

  arm-G (현행) = **gpt-4o-mini** 1차 + 위 글루 전부   ← orthus 현행 프로덕션 슬롯
  arm-K (교체) = **solar** 1차 + 위 글루 전부         ← = D8의 R+ (98.8%, 재사용)
```

부수 보고(맨몸 대조, 게이트 아님): gpt t0 단독 vs solar t0 단독(73.5%, 기측정).

## 3. 판정 기준 (결과 보기 전 고정)

**주판정 = 비열등성.** 마진 **δ = 2.0%p** (절대). 근거: orthus의 이 태스크는 read-only
집계 질의이고 오답은 재질문으로 회복 가능하다. 2%p는 1,438문항에서 약 29문항 — 벤더 리스크
제거·지연 개선(698ms vs 1,110ms)과 맞바꿀 만한 상한으로 **사전에** 정한다.

| 결과 | 문안 |
|---|---|
| arm-K − arm-G 의 95% CI 하한 **> 0** | **"국내가 유의하게 낫다"** (우월성 성립) |
| CI 하한 > **−2.0%p** (0 포함 가능) | **"바꿔도 손해 없다"** (비열등 성립) |
| CI 하한 ≤ **−2.0%p** | **"교체는 실질 손해"** → §5 문안으로 보고 |

- 검정: paired McNemar(우월성) + paired 부트스트랩 10k로 차이의 95% CI(비열등성).
- **단일 판정 1회.** 마진·글루·판정셋을 결과 보고 바꾸지 않는다(D7 §7 상속).
- 두 arm 모두 천장(>97%)에 붙어 변별 불가면 그 사실을 **한계로 명시**하고, 맨몸 대조를
  보조 근거로 병기한다(천장 효과는 D8에서 이미 관측 — `d7-results.md` E14).

## 4. 이 측정이 **주장할 수 없는** 것 (범위 한계 — 보고서에 필수 병기)

1. **태스크 1종뿐이다.** 이 결과는 `structured NL→SQL` 한 작업에만 해당한다. orthus의 다른
   10+ LLM 작업(decompose·distill·wiki_qa·email_draft…)에 일반화하지 않는다. 특히
   **decompose는 국내가 유의하게 지는 것이 기측정**이며 본 측정은 그것을 뒤집지 않는다.
2. **시스템 주장이지 모델 주장이 아니다.** arm-K가 이겨도 "solar > gpt-4o-mini"가 아니라
   "solar+글루 ≥ gpt+글루"다. 글루는 양쪽에 동일하므로 글루의 공을 국내 모델에 귀속시키지
   않는다.
3. **D8 판정셋은 solar에게 유리했을 수 있다**(E14: solar t0가 D7 63.0 → D8 73.5로 상승,
   신규 합성 12DB 구성 기인 추정). 이 셋에서의 우위는 셋 특성과 교락(confound)될 수 있다.
4. 비용/지연은 본 측정 대상이 아니다(글루가 5콜을 쓰므로 양 arm 모두 5배 비용).

## 5. 실패 시 보고 문안 (미리 써둔다)

> 현행 GPT 슬롯을 국내 solar로 교체하면 이 태스크에서 **δ=2%p를 넘는 실질 손해**가 관측됐다.
> 벤더 금지가 확정 제약인 이상 교체는 진행하되, **손해 없는 교체라고 주장하지 않는다.**
> 손실 폭을 명시하고, 글루 보강 또는 태스크별 예외로 메울 방안을 별도 과제로 남긴다.

## 7. 추가 사전선언 — 배포 수준 주장 (2026-07-17 추가, **결과 미확인 상태**)

> 추가 시점 baseline 캡처 186/7190, **gpt 점수 미산출·미열람**. owner가 원하는 결론이
> "국내 모델을 잘 쓰면 GPT를 이긴다"임을 밝혀 왔으므로, 그 주장이 성립할 조건을 **지금**
> 고정한다. §1~§6은 변경하지 않는다.

### 7.1 두 주장을 분리한다 (핵심 — 섞으면 거짓말이 된다)

| | 주장 | 비교 | 검정 |
|---|---|---|---|
| **C1 부품** | "국내 모델이 GPT에 뒤지지 않는다" | solar+글루 **vs gpt+글루** (글루 동일) | §3 비열등, δ=2%p |
| **C2 배포** | "국내 스택을 잘 조립하면 **현행 배포 상태**를 이긴다" | 국내 스택 vs **gpt-4o-mini 맨몸 단일 슬롯**(= orthus 현행 `ORTHUS_LLM=openai`) | 우월성, McNemar p<0.05 ∧ 부트스트랩 CI 하한 > 0 |

C2의 국내 스택 후보 **2종**(둘 다 사전 고정, 사후 선택 금지 — 각각 보고):
- **C2a** = solar + R+ 글루 (= D8의 R+, 98.8% 기측정) — 정확도 최대, 외부 API 의존 잔존
- **C2b** = **SFT EXAONE 1.2B + snap + 자기일관성**(91.9% 기측정) — **외부 API 0콜, 자체 GPU**
  (벤더 금지 관점에서 가장 강한 구성. c8의 폴백(solar/ax)을 뺀 순수 자체 스택)

### 7.2 C2에 **반드시 병기할 인과 단서** (위반 시 보고서 무효)

C2가 성립해도 **"국내 모델이 GPT보다 우수하다"로 쓰지 않는다.** E15에서 실측된 대로
이득의 대부분은 **글루(스냅 +22.7p)**에서 오고, 글루는 모델 국적과 무관하다. 따라서 C2의
정직한 문장은 다음 형태로만 쓴다:

> "현행 GPT 단일 슬롯을 **국내 모델 + 결정론 글루 스택으로 교체하면 시스템 정확도가
> 오른다**(+X%p). 단 이 이득은 국내 모델의 우수성이 아니라 **글루** 때문이며, 같은 글루를
> GPT에 얹으면 GPT도 동등하게 오른다(C1 결과 병기). 국내 모델의 기여는 **'글루를 얹었을 때
> GPT에 뒤지지 않는다'(C1)**까지다."

**C1이 비열등 실패(국내가 유의하게 열등)로 나오면, C2를 근거로 교체를 정당화하지 않는다** —
그때는 "벤더 금지가 확정 제약이므로 손실을 감수하고 교체하되, 글루로 상당 부분 상쇄된다"로
쓴다(§5 문안 계열).

### 7.3 이 설계가 **공정한 이유** (예상 반박 대응)

"국내+글루 vs GPT 맨몸"은 그 자체로는 불공정하다(글루를 한쪽에만 줌 — 실제로 본 실험에서
같은 실수를 저질렀다가 E15에서 정정). 그럼에도 C2를 재는 이유는, 그것이 **orthus의 실제
before/after**이기 때문이다: 현행 프로덕션은 글루가 없는 gpt 단일 슬롯이고, 제안 스택은
글루가 있다. **C2는 "제품 의사결정" 질문이고, C1은 "과학" 질문이다.** 둘을 반드시 함께
보고해야 독자가 이득의 출처를 오해하지 않는다. C1 없이 C2만 보고하는 것을 금지한다.
