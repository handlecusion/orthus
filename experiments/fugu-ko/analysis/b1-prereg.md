# B1 사전선언 — 글루 기여도 분해 (Glue Ablation)

> 작성 2026-07-21 · 상태 **제안(미승인)** — 승인 시 **LOCKED**로 전환하고 이후 수정 금지.
> `b0-benchmark-suite.md` 공통 규칙 + D7 사전선언 §1·§7·§8을 상속한다.

## 0. 한 줄

**이 파이프라인의 정확도를 지배하는 것은 모델 선택인가, 우리가 만든 결정론 글루인가.**
글루 효과가 모델 효과보다 크면 "국내 모델로 옮겨도 손해 없다"는 방어적 주장이
**"성능의 출처는 우리 시스템이다"**라는 능동적 주장으로 바뀐다.

## 1. 자백 — 이 실험이 우리에게 유리한 지점

1. **글루는 우리가 만들었고 우리 데이터에 맞춰 다듬였다.** `repair.py`의 GROUP BY 제거,
   카탈로그-멤버십 스냅은 orthus 스키마 관찰에서 나왔다. 다른 도메인에서 같은 크기로 재현된다는
   보장이 없다 — §5에 한계로 명시한다.
2. **t3는 글루 효과가 가장 큰 작업일 가능성이 높다.** 실행 신호(0행·에러·null)가 결정론적으로
   존재하는 드문 작업이다. t7·t10을 함께 재는 이유가 이것이며, **t3만으로 일반화하지 않는다.**
3. **"결과 0 = 오답" 규칙은 이 벤치마크의 구멍이다**(D7 §1.1-2 기존 자백 승계). gold에 0이 없는 것은
   생성기 버릇이다. 본 실험은 그 규칙을 **양 arm에 동일 적용**하므로 비교는 공정하나, 절대 수치는
   그만큼 부풀어 있다.

## 2. 측정 대상 — 2요인 완전 교차

```text
요인 A: 모델 (6종, 1차 슬롯만 교체)
  solar · exaone · ax · gpt-4o-mini(현행 베이스라인) · deepseek-v3.2 · claude-sonnet-4-6

요인 B: 글루 사다리 (5단, 누적 — 각 단계는 이전 단계를 포함)
  L0  bare          단일 콜(t0), 후처리 없음
  L1  +snap         카탈로그-멤버십 스냅(값/이름 복사 손상 교정)
  L2  +repair       결정론 SQL 수리 (train/repair.py — GROUP BY 제거 등)
  L3  +k=5 SC       자기일관성 (t0 + 4×t0.7, 실행결과 null 제외 다수결)
  L4  +probe/폴백   probe-0 + null 폴백(배정워커 → 다른 국내 워커)
```

6 × 5 = **30 셀**. 사다리 순서는 사전 고정이며 결과를 보고 재배열하지 않는다.

**판정셋 (동결, 재생성 금지)**

| 작업 | 파일 | n | 채점 |
|---|---|---|---|
| t3 structured | `golden/t3_d8_holdout.json` | 1,438 | 게이트 통과 + 실행결과 일치(결정론) |
| t7 decompose | `golden/e3_control.json` + `e3_missed.json` | 80 | 게이트 판정 일치(결정론) |
| t10 delegation | `golden/t10_holdout2.json` | 38 | 필드 exact(경칭 정규화 적용) |

**주판정은 t3 단독**이다(n=1,438). t7·t10은 **부수 보고**이며 표본이 작아 유의 판정을 하지 않는다
(b0 §2 — MDE 미달 실험으로 승리를 주장하지 않는다).

> **개정 2026-07-21 (LOCK 이전, 하네스 구현 중 발견) — 글루 사다리는 t3에만 존재한다.**
> snap·repair·probe-0은 전부 **SQL 텍스트/실행 신호** 글루라, **t7(decompose)·t10(delegation)에는
> 대응하는 기존 구현이 아예 없다.** 프리레그 §6이 "새 글루를 짓지 말라"고 했으므로 짓지 않았고,
> 두 작업은 전 레벨에서 통과만 하며 `glue.applies=false`를 기록한다.
>
> **따라서 t7·t10의 부수 보고는 평평한 선으로 나온다. 이것을 "글루 효과 없음"으로 읽으면 안 된다 —
> "글루 미구현"이다.** 결과 보고에 이 문장을 반드시 병기한다. 두 해석은 정반대의 함의를 갖는다:
> 전자는 글루가 t3 특수 현상이라는 뜻이고, 후자는 아직 안 만들었다는 뜻이다.
> 본 실험은 둘을 구분하지 못하며, 구분하려면 t7/t10 글루를 만드는 **별도 작업**이 필요하다.
>
> 부수 효과: `--glue-level 4`의 t3 파이프라인은 **D8의 R+ arm과 정의상 동일**하다(1차 워커만 교체).
> 즉 L4 결과는 기존 D8 수치와 직접 대조 가능하다.

## 3. 판정 기준 (결과 보기 전 고정)

두 효과를 **같은 판정셋·같은 채점 함수**로 정의한다.

```text
Δ_glue  = max_L acc(m, L) − acc(m, L0)        모델 m 내부의 사다리 효과 (paired)
Δ_model = max_m acc(m, L) − min_m acc(m, L)   글루 단계 L 고정 시의 모델 효과
```

**주판정.** `min_m Δ_glue(m)` 의 bootstrap 95% CI 하한 > `max_L Δ_model(L)` 의 CI 상한.
즉 **가장 글루 덕을 덜 본 모델의 글루 효과**가 **가장 모델 차이가 컸던 단계의 모델 효과**보다
크면 "글루가 지배적"이 성립한다. 보수적으로 잡은 이유는 반대 방향의 체리피킹을 막기 위해서다.

| 결과 | 문안 |
|---|---|
| CI 비중첩 & Δ_glue 우세 | **"성능을 지배하는 것은 모델이 아니라 글루다"** (주장 성립) |
| CI 중첩 | **"두 효과의 크기를 이 표본으로는 분리하지 못한다"** (주장 철회, 동률로 보고) |
| Δ_model 우세 | **"모델 선택이 글루보다 중요하다"** — 우리 서사와 반대여도 그대로 보고한다 |

**사전 고정 사항**

- 모델 6종은 위 목록으로 고정한다. 실행 후 추가된 모델은 **부수 보고에만** 넣고 주판정에서 제외한다.
- 사다리는 누적이며 단계 건너뛰기 조합(예: L0+L3)은 판정에 쓰지 않는다(탐색 보고만 허용).
- 검정: paired bootstrap 10,000 리샘플, seed 1234. 문항 단위 리샘플.

## 4. 반드시 함께 보고할 것

1. **프론티어 + 글루.** deepseek-v3.2·claude-sonnet-4-6에도 L4까지 동일 적용한다.
   **프론티어+글루가 국내+글루보다 높게 나오면 그대로 보고한다.** 이 실험의 주장은
   "국내가 최고"가 아니라 "글루가 지배적"이므로, 그 결과는 주장을 훼손하지 않는다.
2. **비용·지연.** L3는 5콜이다. 정확도 이득을 **콜 수·지연 증분과 반드시 병기**한다
   (E1 실측 기준 캐스케이드는 1.22×, 자기일관성은 5×).
3. **단계별 기여 분해.** L0→L1→L2→L3→L4 각 구간의 증분과, 각 구간에서 **구제된 문항 수 / 새로
   망가진 문항 수**를 함께 낸다. 순증만 보고하지 않는다.
4. **천장 효과.** t3에서 상위 arm이 97% 이상에 붙으면 변별 불가를 **한계로 명시**하고,
   맨몸(L0) 대조를 보조 근거로 병기한다(D8에서 이미 관측).

## 5. 이 실험이 주장할 수 없는 것

1. **일반화 금지.** t3는 결정론 실패 신호가 유난히 풍부한 작업이다. 글루 효과의 크기는
   작업마다 다르며, 본 실험은 3작업만 잰다.
2. **도메인 이전 금지.** 글루는 orthus 스키마 관찰에서 나왔다. 다른 회사 데이터에서 같은
   +25%p가 나온다고 말할 수 없다.
3. **"국내 모델이 우수하다"로 읽지 않는다.** 글루는 양쪽에 동일하므로 글루의 공을 특정 벤더에
   귀속시키지 않는다(D9 §4.2 상속).
4. **비용 중립이 아니다.** L3·L4는 호출 수를 늘린다. 정확도만 떼어 자랑하지 않는다.
