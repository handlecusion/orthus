## 0. 왜 4개를 새로 만드는가

11모델 E2E(2026-07-21, n=145)는 **비열등성 주장에는 충분하지만 우위 주장에는 구조적으로 무력하다.**
근거는 그 보고서 자신이다.

| 관측 | 함의 |
|---|---|
| 12개 비교 대상 중 상위 9개가 전부 통계 동률 | 표본이 2%p대 차이를 분해하지 못한다 |
| n=145에서 유의가 나오려면 불일치 20쌍 중 **15:5** 이상 필요(exact binomial p≈0.041) | V1↔V2 3문항 차 → p=0.375. Sonnet 불일치 4:4 → p=1.000 |
| t6 전 모델 19/20, t9 전 모델 32/32(Haiku 제외) | 두 슬롯의 정보량 ≈ 0 |
| oracle 상한 124/145 = 85.5% | 26문항은 어떤 모델도 못 맞힌다 |
| t3 bare 73.5% → 글루 후 98.8%(별도 n=1,438) | **글루 효과(+25%p)가 모델 효과(±2%p)의 한 자릿수 위** |

마지막 줄이 이 스위트의 설계 근거다. **측정 대상을 "어느 모델이 나은가"에서 "무엇이 성능을
지배하는가"로 옮긴다.** 이는 우리에게 유리한 동시에 더 사실이다.

## 1. 무효 원칙 (D7 §1 상속)

- 각 사전선언 문서에 **없는 기준으로 사후에 승리를 주장하면 그 주장은 무효다.**
- 판정셋·마진·채점 함수·문안은 **결과를 보기 전에** 고정하고, 결과를 본 뒤 바꾸지 않는다.
- 수정이 필요하면 문서를 고치지 않고 **새 버전 문서를 만들고 사유를 남긴다.**
- 탐색적 관측은 **가설의 출처로만** 유효하고 승리 근거가 될 수 없다.

## 2. 표본·검정력 정책 (신규 — 이번 스위트의 핵심 방어)

**n=145로 2%p를 재려는 시도를 금지한다.** 각 사전선언은 아래 셋을 **결과 보기 전에** 명시한다.

1. **최소검출효과(MDE)** — 이 표본에서 유의를 만들 수 있는 최소 차이. 주장하려는 효과가 MDE보다
   작으면 그 실험은 설계 단계에서 기각한다.
2. **천장/바닥 배제** — 사전 파일럿에서 전 대상이 동점인 슬롯은 **헤드라인 세트에서 제외**하거나
   난이도를 올린다. 정보량 0인 문항으로 n을 채우면 검정력만 희석된다.
3. **동률의 해석** — 동률은 "우리가 이겼다"가 아니라 **"이 표본은 구분하지 못한다"**로만 쓴다.

## 3. 다중비교 (D7 §7 상속)

- 각 벤치마크는 **주판정 1개**만 갖는다. 나머지는 전부 부수 보고(탐색)다.
- 스위트 전체 주판정 4개에 **Holm 보정**을 적용한다.
- p<0.05만 유의로 표기하되 **0.05 경계 근접치를 확정 유의차로 승격하지 않는다**(기존 원칙).
- 검정: 쌍대 exact McNemar(우월성) + paired bootstrap 10,000 리샘플 CI(비열등성/효과크기), seed 1234.

## 4. 공정 조건 (11모델 E2E에서 상속, 강화)

- **모델별 전용 프롬프트 튜닝 없음.** 프로덕션 함수·few-shot·프리필터를 그대로 통과시킨다.
- **글루는 전 arm에 동일 적용한다.** 우리 모델에만 글루를 얹고 프론티어를 맨몸으로 세우면 그건 리깅이다.
  B1은 오히려 **프론티어에도 글루를 얹었을 때** 무슨 일이 일어나는지를 판정 대상으로 삼는다.
- 실행 오류(429 등)는 채점셋에서 제외하고, **제외 문항 수와 겹침을 반드시 보고**한다.

## 6. 산출물 규약

- 신규 문항은 `golden/b{1..4}_*.json`, 매니페스트는 `e2e/` 규약(`manifest_schema.md`)을 따른다.
- 외부 데이터는 **커밋하지 않는다** — 다운로드 스크립트 + `sha256` 고정만 커밋(재배포 금지 자산 다수).
- 각 실험은 `analysis/b{n}-results.md`에 결과를 남기고, **사전선언 문서는 사후 수정하지 않는다.**
