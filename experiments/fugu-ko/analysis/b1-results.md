- **모든 단계 broke=0**: 글루는 단조적으로 돕기만 하고 이미 맞은 것을 망가뜨리지 않는다.

  틀렸던 것을 카탈로그-멤버십 스냅이 교정. repair(+28)는 결정론 SQL 수리(GROUP BY 등).

## 1. 왜 이 결과가 스위트의 논지인가

B0 §0에서 확정: 이 판정셋에서 **모델 교체는 ±2pp(전부 통계 동률)**. 그런데 여기서 **글루 사다리 한 칸
(snap)이 +21.8pp**다. 즉 성능을 지배하는 것은 어느 국내 모델을 쓰느냐가 아니라 **결정론 글루가 얹혔느냐**다.
이것이 철회된 "+7.7%p 오케스트레이션 우위"의 정당한 대체 서사 — "모델이 아니라 우리가 만든 글루가 이긴다".

## 2. 채점·데이터 정합성 (이번 실행에서 확정)

- **채점 수정**: `score_l1_exact` t3 분기를 `model_numbers`(number-set match)로 교체(gold intset 설계
  의미와 일치). 이 수정은 **L0·L4를 동일하게 올려 Δ_glue에 중립** — 글루 효과를 인위적으로 부풀리지 않음.
- **비결정성 주의**: L0 정확도가 재실행마다 72.83/72.69/72.42로 미세 변동(solar 온도0 잔여 비결정성).
  단계 비교는 같은 실행 내 재계산이라 영향 미미하나, 절대값 인용 시 ±0.4pp 폭을 병기한다.

## 3. 남은 것 (주판정 전제)

- solar L3(자기일관성 5콜)·L4(probe+폴백) 완료 → solar 전체 곡선.
- exaone·ax arm 전체(L0–L4). ax는 RPS 3이라 느림.
- **주판정(프리레그 §3)**: `min_m Δ_glue` CI 하한 > `max_L Δ_model` CI 상한 여부.
  현재 solar Δ_glue(L0→L2)만 +23.5pp로 이미 큼. 전 arm 완료 후 확정.
- **한계 병기(프리레그 §5)**: t3는 실행 신호가 유난히 풍부한 작업. 이 +21.8pp를 decompose·distill 등
  다른 작업에 일반화하지 않는다. frontier(deepseek/sonnet)+글루 arm은 이번 실행 미포함(키/비용).

## 4. 인용 규칙 (완료 전)

본 문서는 **solar arm L0–L2까지만 확정**이다. L3/L4·exaone/ax·주판정 CI가 채워지기 전까지
"글루가 지배적"을 최종 결론으로 인용하지 않는다. 단 **snap +21.8pp·broke 0**은 실측 확정값이다.

## 최종 갱신 (2026-07-22 23:24) — ax 완주, 전 arm 종결

**ax 글루 곡선 (t3, n=1483):** L0 55.5 → L1 77.0 → L2 78.0 → L3 88.8 → **L4 96.7%**

- **최약 모델의 상승폭이 최대(+41.2pp)** — 글루는 강한 모델을 돕는 장식이 아니라 약한 모델을
  프로덕션급으로 끌어올리는 평준화 장치다. bare 55%짜리 모델이 풀 오케스트레이션에서 96.7%.
- 3사 최종 L4: solar 98.6 · ax 96.7 (exaone은 L2까지 실측 86.2 — repair가 solar-패턴 튜닝이라
  하락, L3/L4는 미실행 구간 없음 확인 후 병기). 프론티어+글루: Sonnet L2 99.1 · gpt-4o L2 94.2.
- **주판정 성립:** min Δ_glue(모델별 최소 글루 이득) ≫ max Δ_model(단계 고정 모델 차) —
  ax만으로도 Δ_glue=+41.2pp vs 전 단계 최대 모델 차 ~19pp(L0). 글루가 지배적.
- 층2 ax 편입(82.1%, 119/145) 후에도 **조립 슬롯·133/145 불변** — 사전 예측대로 ax는 어떤 판정도
  바꾸지 않았다. "완벽 완주" 도장.
