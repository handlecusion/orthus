## 0. 한 문장 — 답은 YES

**작업별로 국내 모델을 역할 배정한 오케스트레이션이 최신 프론티어와 통계적 동률이고, 원가·지연·벤더
리스크는 국내가 압도한다.** 그리고 그 경쟁력의 출처는 국내 모델의 우수성이 아니라 **우리가 만든
결정론 시스템(게이트·글루·역할 배정)**이다 — 같은 시스템을 프론티어에 얹어도 결과는 수렴한다.

## 2. 왜 경쟁하는가 — 메커니즘은 "시스템"이다 (층1: t3 파이프 내)

같은 결정론 파이프(compile→gate→execute→snap→repair)에 모델만 갈아끼운 t3 글루 곡선:

| | L0 맨몸 | L1 +snap | L2 +repair | L4 풀 |
|---|---|---|---|---|
| gpt-4o (프론티어) | 74.0 | 94.5 | 94.2 | — |
| **Sonnet 4.6** (프론티어) | 93.1† | — | **99.1** | — |
| solar (국내) | 72.2 | 94.2 | 96.2 | **98.6** |
| exaone (국내) | 63.8 | 89.6 | 86.2‡ | |

- **글루가 국내·프론티어를 똑같이 +20pp 올린다** (solar 72→94, gpt-4o 74→94). 병목을 푸는 건 벤더가
  아니라 우리 시스템 — snap 한 칸이 +22pp, 모델 교체는 ±2pp.
- †Sonnet 맨몸이 93%로 높은 건 프론티어 원 실력. 하지만 글루를 얹으면 solar도 96~98%에 도달해
  **격차가 사라진다**. ‡exaone L2 하락은 repair 글루가 solar SQL 패턴에 튜닝돼 exaone엔 안 맞은 것
  — **글루가 모델-특수적일 수 있다는 정직한 신호**.
- **비용**: 값싼 snap(1콜)이 거의 전부. 자기일관성(L3)은 5배 비용에 +1pp·첫 파손 1건 → "더 쌓을수록
  좋다"가 아니다.

## 3. 어디서 경쟁하는가 — 시스템 진단 (B2/B3/B4)

조립이 프론티어와 붙는 이유/한계를 각 벤치마크가 설명한다. **일부는 우리 가설을 반박한다 — 그게 신뢰도다.**

| 벤치마크 | 결론 | 조립 경쟁력에의 함의 |
|---|---|---|
| **B2** 계약 이행 | Haiku 펜스붕괴 C1 37.5→77.5%(배선 +40p) | 프로덕션 성능은 추론력 아닌 **출력 계약**이 가름 — 국내 모델도 배선으로 복구 가능 |
| **B3-R1** 게이트 거부 | 게이트가 맨몸보다 **더 샘**(가설 반증) | SQL 게이트는 refuse 레이어가 아님 — 안전은 모델 abstain에서. 조립의 약점 |
| **B3-R2** 추상화 | grounding은 안전 아닌 **유용성** | 국내 모델도 grounding 얹으면 사기업 지식 77~88% 답변. 모델차가 누출 지배(solar 2 vs exaone 11) |
| **B3-R3** 위임 오탐 | 안전은 **사람 검토 정책**에서 | 국내 exaone이 위임 판별 21/22로 프론티어 앞섬(t10 승부처의 근거) |
| **B4-X1/X2** 판정자 κ | 판정자 사람 수준 검증(PASS) | 위 승률들의 해석 근거 확보 |
| **B4-X3** 한국어 스키마 | 게이트통과 99.5% (부호 성립) | 국내 컬럼 링킹이 외부 한국어 표에서도 됨 |
| **B4-X4** 임베딩 | Solar>현행 2/2, 2.3배 빠름 | 국내 임베딩이 검색 슬롯에서도 경쟁 + 지연 우위 |

## 4. 관통 인사이트 — 하나의 사실, 세 얼굴

**orthus의 structured 레이어는 "확신에 찬 0을 진짜로 신뢰"한다.** 이 단일 아키텍처 선택이 셋에 동시에:
- **B1**: 캐스케이드가 confident-0 재시도 제외 → 그 오답은 글루가 못 고침(실 쿼리엔 드묾).
- **B3-R1**: 같은 이유로 없는-컬럼(0 반환)을 게이트가 못 잡음 → refuse 레이어 아님.
- **B4-X3**: `schema_ok`가 키를 데이터로 취급 → 한국어 컬럼 공짜 통과(장점)이자 미검증(단점).
→ 실 쿼리 최적화가 적대적 out-of-schema엔 취약. 세 벤치마크가 독립적으로 짚었다.

**그 외 관통:**
- **"안전해 보이는 baseline"은 대개 무응답**(R1 abstain·R2 0%). 안전은 유용성과의 트레이드로만 의미.
- **진짜 병목은 n(표본·모델 수)** — B2 6모델로 분산비 유의성 미달. 반면 조립 vs gpt-4o는 145로도 유의.
- **성능은 모델이 아니라 시스템에서 온다 — 좋은 쪽(글루 +22pp)도 나쁜 쪽(게이트 미보호)도.**

## 5. 대회 서사

**"국내 모델 오케스트레이션은 최신 프론티어(gpt-5.3/Sonnet 4.6)와 정확도 동률이면서, 원가·지연·벤더
독립성에서 앞선다. 그 경쟁력은 국내 모델이 특별해서가 아니라, 우리가 만든 결정론 시스템(게이트·글루·
역할 배정)이 벤더 격차를 덮기 때문이다 — 같은 시스템을 프론티어에 얹어도 결과는 수렴한다."**
